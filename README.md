# Share Diary

> 나만의 일기, 우리들의 일기

## 📌 프로젝트 소개
**Share Diary**는 하루를 기록하고, 감정을 나누고, 다른 사용자와 소통할 수 있도록 기획한 **일기장 웹 프로젝트**입니다.  
사용자는 개인 일기장을 통해 자신의 하루를 기록할 수 있고, 공유 일기장을 통해 익명의 사용자들과 일상을 나눌 수 있으며, 교환 일기 기능을 통해 특정 사용자와 1:1로 추억을 기록할 수 있습니다.

## 🔍 프로젝트 특징
- 하루의 감정과 일상을 기록할 수 있는 **일기장 서비스**
- 다른 사용자와 감정을 공유할 수 있는 **공유 일기 기능**
- 특정 사용자와만 기록을 주고받는 **교환 일기 기능**
- 게시판과 댓글, 추천 기능을 통해 **커뮤니티 요소 강화**
- 관리자 로그 조회 기능을 통한 **운영 페이지 구현**

---

## 📚 프로젝트를 통해 배운 점
이번 프로젝트를 통해 단순히 개별 페이지를 만드는 것에서 끝나는 것이 아니라,  
**공통 레이아웃 구성**, **페이지 간 이동 흐름**, **게시판 데이터 출력**, **UI 통일성 유지**의 중요성을 경험할 수 있었습니다.

특히 메인 페이지와 공통 UI 요소를 담당하면서  
사용자가 처음 접하는 화면의 구성과 동선이 서비스 인상에 큰 영향을 준다는 점을 배웠고,  
팀 프로젝트에서 역할 분담과 파일 통합, 스타일 정리의 중요성도 함께 익힐 수 있었습니다.
